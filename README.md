## Descripción

Análisis exploratorio y modelado de clasificación para predecir si un cliente de tarjeta de crédito entrará en *default* el mes siguiente. Se comparan Regresión Logística y Random Forest.

## Dataset

[Default of Credit Card Clients](https://archive.ics.uci.edu/dataset/350/default+of+credit+card+clients) – UCI Machine Learning Repository. 30.000 clientes de Taiwán (2005), 23 variables explicativas y 1 variable objetivo.

## Archivos

- [EDA_default_tarjetas.ipynb](EDA_default_tarjetas.ipynb): notebook principal (Google Colab).
- [eda_default_tarjetas.py](eda_default_tarjetas.py): exportación del notebook a script Python.
